# Legacy generators

`_insertFollowUp.py` bulk-generated the `followUp` blocks in `src/disorders.js`
in April 2026. It is kept for the record — much of the citation audit since
(see docs/citation-claims-review.md) traces to text this script inserted — but
it must not be run again: its output was never source-checked, and the
knowledge base is now maintained by hand against verified references.
